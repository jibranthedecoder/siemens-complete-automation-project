# PLC and HMI Implementation

This section contains the Siemens TIA Portal implementation phase of the project.

Implementation areas:
- Siemens GRAPH sequence control
- Modular FB/FC architecture
- Motor and valve control
- Analog sensor scaling
- PID Compact control
- Alarm and fault handling
- Automatic, manual, and test modes
- WinCC HMI implementation
- Process sequence logic

Simulation and validation were completed using PLCSIM Advanced and Siemens SIMIT.
