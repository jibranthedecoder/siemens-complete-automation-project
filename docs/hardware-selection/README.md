# Hardware Selection

This folder contains Siemens S7-1500 hardware selection and I/O planning documentation.

Main components:
- CPU 1511-1 PN
- Digital I/O modules
- Analog I/O modules
- Siemens KTP700 Basic HMI
- SITOP 24VDC power supplies
- PROFINET communication

Engineering topics:
- Power supply sizing
- I/O allocation
- Sensor and actuator mapping
- PLC and HMI architecture
- Field device integration
