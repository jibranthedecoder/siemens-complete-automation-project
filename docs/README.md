# Documentation

This folder contains project documentation for the Siemens chemical process automation project.

Recommended structure:

- `functional-specification/` — P&ID interpretation and functional process description
- `hardware-selection/` — Siemens S7-1500 hardware, power supplies, HMI, and I/O planning
- `implementation/` — TIA Portal implementation notes and PLC/HMI structure
- `simulation/` — SIMIT and PLCSIM validation evidence

## Current documentation set

The project should include at least:

1. Functional specification PDF
2. TIA Selection Tool hardware order list PDF
3. TIA Portal project archive `.zap16`
4. TIA Portal program PDF printout
5. Simulation evidence PDF, screenshots, or video

Use clear file names with lowercase words and hyphens. Avoid spaces in repository file names.
