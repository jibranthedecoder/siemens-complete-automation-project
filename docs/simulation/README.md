# Simulation and Validation

This section contains simulation and validation material for the Siemens chemical process automation project.

Simulation environment:
- Siemens PLCSIM Advanced
- Siemens SIMIT
- Siemens TIA Portal V16

Validation scope:
- GRAPH sequence progression
- Valve operation
- Motor operation
- Sensor value simulation
- Batch completion
- Startup and shutdown testing
- Alarm and fault behavior

Recommended files:
- `simit-process-simulation.pdf`
- simulation screenshots
- validation videos
